แจ้งแพทย์หรือเภสัชกรเกี่ยวกับยา วิตามิน และผลิตภัณฑ์เสริมอาหารที่ใช้อยู่ เพื่อประเมินความเสี่ยงจากการใช้ร่วมกัน

🧑‍⚕️

ปรึกษาผู้เชี่ยวชาญ

ไม่ปรับขนาดยา หยุดยา หรือใช้ยาของผู้อื่นด้วยตนเอง หากเกิดอาการผิดปกติหลังใช้ยาให้ขอคำแนะนำจากบุคลากรทางการแพทย์

ข้อจำกัดของฐานข้อมูล: ไฟล์ต้นฉบับมีชื่อสามัญ ความแรง รูปแบบยา หมวดหมู่ ATC Code และ Reorder Level แต่ไม่มีข้อบ่งใช้ ขนาดและวิธีใช้ ข้อห้ามใช้ ผลข้างเคียง หรือปฏิกิริยาระหว่างยา ดังนั้น Dashboard นี้แสดงเฉพาะข้อมูลที่มีในไฟล์ และไม่ใช้แทนคำแนะนำจากแพทย์หรือเภสัชกร ข้อมูล Reorder Level เป็นนโยบายสมมติของร้านยา ไม่ใช่ข้อมูลสำหรับผู้ป่วย
