อ่านฉลากและเอกสารกำกับยา

ตรวจสอบชื่อยา ความแรง รูปแบบยา วิธีใช้ และวันหมดอายุก่อนใช้ยา หากข้อมูลไม่ชัดเจนควรถามเภสัชกร

⚠️

ระวังการใช้ยาร่วมกัน

แจ้งแพทย์หรือเภสัชกรเกี่ยวกับยา วิตามิน และผลิตภัณฑ์เสริมอาหารที่ใช้อยู่ เพื่อประเมินความเสี่ยงจากการใช้ร่วมกัน

🧑‍⚕️

ปรึกษาผู้เชี่ยวชาญ

ไม่ปรับขนาดยา หยุดยา หรือใช้ยาของผู้อื่นด้วยตนเอง หากเกิดอาการผิดปกติหลังใช้ยาให้ขอคำแนะนำจากบุคลากรทางการแพทย์

ข้อจำกัดของฐานข้อมูล: ไฟล์ต้นฉบับมีชื่อสามัญ ความแรง รูปแบบยา หมวดหมู่ ATC Code และ Reorder Level แต่ไม่มีขนาดและวิธีใช้ ข้อห้ามใช้ ผลข้างเคียง หรือปฏิกิริยาระหว่างยา ส่วน “เลือกตามอาการ” เป็นข้อมูลทั่วไปที่จัดทำเพิ่มเพื่อช่วยค้นหา ไม่ใช่การวินิจฉัยหรือสั่งยา Dashboard นี้ไม่ใช้แทนคำแนะนำจากแพทย์หรือเภสัชกร ข้อมูล Reorder Level เป็นนโยบายสมมติของร้านยา ไม่ใช่ข้อมูลสำหรับผู้ป่วย
